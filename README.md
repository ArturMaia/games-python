# 🎮 PORTAL DE JOGOS PYTHON

### Bem-vindo ao universo dos jogos desenvolvidos em Python!

Este repositório reúne diferentes jogos criados utilizando Python, desde desafios de raciocínio e adivinhação até jogos de lógica e entretenimento.

Explore os projetos, conheça suas mecânicas e descubra novas formas de se divertir!

---

## 🕹️ CATÁLOGO DE JOGOS

Aqui você encontra os projetos disponíveis no portal. Cada jogo possui uma pasta própria, com seu código-fonte e um README contendo informações sobre as regras e o funcionamento.

### 🎯 Jogos disponíveis

- **Jogo da Forca:** descubra a palavra secreta antes que suas tentativas acabem! Escolha entre diferentes temas e teste seus conhecimentos.
- **QuizBR:** teste seus conhecimentos sobre diversos assuntos da cultura brasileira.
- **Jogo da Cobra:** um clássico dos jogos, também uma homenagem a linguagem usada.
- **Tetris:** teste suas habilidades lógicas com esse jogo clássico.
  
*Novos jogos serão adicionados ao catálogo conforme o desenvolvimento de novos projetos.*

---

## 🚀 COMO JOGAR?

Para experimentar qualquer um dos jogos:

1. Escolha um jogo no catálogo.
2. Acesse a pasta correspondente.
3. Leia o README individual para conhecer as regras e instruções.
4. Verifique os requisitos necessários para execução.
5. Execute o arquivo Python e aproveite!
